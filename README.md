Project Description

This project is a simple console-based rule chatbot developed in Python using pattern matching and predefined responses. The chatbot can interact with users through greetings, small talk, help commands, and a small knowledge base. It also stores conversation history during runtime.

The main purpose of this project is to demonstrate basic chatbot development concepts using Python fundamentals such as loops, conditional statements, lists, dictionaries, and string handling.

This chatbot does not use Machine Learning or Artificial Intelligence models. Instead, it works using rule-based logic and keyword matching.

How the Chatbot Works

The chatbot continuously accepts user input from the console.

It checks the input against predefined patterns such as:

greetings
help commands
small talk
knowledge-based questions

If a match is found, the chatbot returns the appropriate response.

If no rule matches, the chatbot displays a default response.

Example Conversation
You: hello
Bot: Hello! How can I help you?

You: what is python
Bot: Python is a high level programming language.

You: how are you
Bot: I am fine. Thanks for asking.

You: bye
Bot: Goodbye!
